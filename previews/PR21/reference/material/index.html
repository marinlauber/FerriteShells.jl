Linear Elastic Material

FerriteShells.LinearElastic — Type
LinearElastic(E, ν, thickness=1.0; β=1.0)

Linear elastic shell material defined by Young's modulus E, Poisson's ratio ν, and thickness thickness.

β is a dimensionless bending scale factor that decouples the bending/shear response from the membrane response: the bending stiffness becomes D = β · C · t³/12 and the transverse-shear stiffness scales likewise, while the membrane stiffness A = C · t is unaffected. β = 1 recovers the physical shell; β → 0 approaches a pure membrane (tension-field limit). At exactly β = 0 the rotation DOFs are unconstrained and the assembled tangent is singular — use a small positive β (e.g. 1e-4) for a near-membrane response.

Hyperelastic Material

FerriteShells.Hyperelastic — Type
Hyperelastic(W, thickness=1.0)

Incompressible hyperelastic shell material defined by a full 3D strain energy density W(C::SymmetricTensor{2,3,T}) -> T.

The plane-stress + incompressibility constraint det(C) = 1 is enforced internally. C₃₃ is determined analytically from the in-plane metric C_αβ and transverse shear C_α3 = γ_α (no iteration):

\[C_{33} = \frac{1 - 2C_{12}\gamma_1\gamma_2 + C_{22}\gamma_1^2 + C_{11}\gamma_2^2}{\det_2(C_{\alpha\beta})}\]

W can be any standard incompressible strain energy expressed in terms of the invariants I₁ = tr(C), I₂ = ½((tr C)² − tr C²) with det(C) = 1.

Example — Neo-Hookean incompressible

μ = 80.0e3; t = 1.0e-3
W_NH(C) = μ/2 * (tr(C) - 3)
mat = Hyperelastic(W_NH, t)

Example — Mooney–Rivlin

c₁ = 40.0e3; c₂ = 20.0e3; t = 1.0e-3
W_MR(C) = c₁*(tr(C) - 3) + c₂*((tr(C)^2 - C ⊡ C)/2 - 3)
mat = Hyperelastic(W_MR, t)
